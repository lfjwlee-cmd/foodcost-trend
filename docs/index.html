Trend Menu Clipping

아직 첫 리포트가 발행되지 않았습니다

매일 오전 6시 30분(KST)에 전날 올라온 한국 음식·신메뉴 유튜브 콘텐츠를 모아 이 페이지에 발행합니다. 시작하려면 유튜브 API 키 하나만 등록하면 됩니다.

왜 키가 필요한가
실측해보니 GitHub 서버 IP에서는 유튜브가 개별 영상 조회를 전부 차단합니다 (40건 중 40건 Sign in to confirm you're not a bot). 공식 API로는 이 문제가 없고, 무료 할당량(하루 10,000 유닛)의 약 6%만 씁니다.

  1. console.cloud.google.com → 새 프로젝트 생성
  2. API 및 서비스 → 라이브러리 → YouTube Data API v3 → 사용 설정
  3. 사용자 인증정보 → 사용자 인증정보 만들기 → API 키 → 복사
  4. 저장소 Settings → Secrets and variables → Actions → New repository secret
    Name YOUTUBE_API_KEY, Value 복사한 키
  5. Actions 탭 → Daily Trend Menu Report → Run workflow

이후로는 매일 아침 자동으로 갱신됩니다. 실행 성공·실패 여부는 Actions 탭에서 확인할 수 있고, 발행 전 자동 검증을 통과하지 못한 날은 잘못된 리포트로 덮어쓰지 않고 이전 리포트를 그대로 둡니다.
